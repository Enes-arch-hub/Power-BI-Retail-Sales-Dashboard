# 📊 Power BI Retail Sales Dashboard

## Project Overview

This project focuses on analysing retail sales data using **Microsoft Power BI** to transform raw transaction records into meaningful business insights.

The dashboard provides an overview of sales performance, helping users understand revenue trends, customer contributions, regional performance, and payment preferences.

## 🎯 Project Objectives

- Analyse overall retail sales performance.
- Identify the highest-performing product categories.
- Compare revenue across different regions.
- Examine monthly revenue trends.
- Understand customer purchasing contributions.
- Analyse revenue by payment method.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

## 📈 Dashboard Features

1. **Total Revenue:** Overall revenue generated.
2. **Revenue by Category:** Performance comparison across product categories.
3. **Revenue by Region:** Geographical sales performance.
4. **Monthly Revenue Trend:** Revenue performance over time.
5. **Revenue by Payment Method:** Comparison of customer payment preferences.
6. **Revenue by Customer:** Customer contribution analysis.
7. **Detailed Sales Transactions:** Transaction-level information.
